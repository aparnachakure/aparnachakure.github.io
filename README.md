# Aparna Chakure — Portfolio Website

A responsive static portfolio for showcasing data analytics, business intelligence, and AI-assisted workflow projects.

## Files
- `index.html` — portfolio content and page structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, scroll progress, and current year

## Before publishing
Please verify these items:
1. Confirm that every experience bullet reflects work you personally performed.
2. Confirm the dates for independent project work and VS Techworks collaboration.
3. Confirm that Power BI reporting at Admissions Made Easy was part of your actual work.
4. Add your actual LinkedIn profile URL in the contact section (replace the placeholder).
5. Review every project link and ensure the repositories are public and current.
6. The site intentionally avoids unverified numeric impact claims. Add measured outcomes only when you can explain how they were calculated.

## Preview locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
1. Create a new public repository, e.g. `aparnachakure.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will be `https://aparnachakure.github.io/`.

Alternatively, deploy the folder to Vercel as a static site.
