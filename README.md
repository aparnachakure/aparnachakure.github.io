# Aparna Chakure — Personal Portfolio Website

This repository contains the source code for my personal data analytics portfolio website: **[https://aparnachakure.github.io/](https://aparnachakure.github.io/)**

The site is designed to showcase my experience in **Data Analytics, Business Intelligence, SQL database querying, and dashboard design** through end-to-end case studies and verified career history.

---

## 🛠️ Built With

- **HTML5 & Modern CSS3** — Responsive layout, CSS Custom Properties (variables), and accessibility standards.
- **Vanilla JavaScript (ES6+)** — Reading progress tracking, Light/Dark theme switcher, and clipboard utilities.
- **Typography** — Plus Jakarta Sans & JetBrains Mono (via Google Fonts).
- **Deployment** — Hosted directly on GitHub Pages.

---

## 🚀 Featured Projects Highlighted

1. **[FinPulse BI — Personal Finance Tracker & Executive BI Dashboard](https://aparnachakure.github.io/finance-tracker/)**
   - Single-Page Web Application featuring real-time KPI scorecards, 6-month cash-flow trends with Chart.js, 50/30/20 budget framework analysis, and an interactive MySQL query showcase.
   - [Source Repository](https://github.com/aparnachakure/finance-tracker)

2. **[Healthcare Operations & Patient Analytics](https://github.com/aparnachakure/Healthcare-operations-analytics)**
   - Hospital operational intelligence analyzing 1,800 patient admissions across 6 clinical departments. Evaluated Average Length of Stay (ALOS), department bed occupancy, and 30-day readmissions using PostgreSQL, Python (Pandas), and Power BI DAX.

3. **[Retail & Superstore Sales Analytics Lab](https://github.com/aparnachakure/Sales-analytics-learning-lab)**
   - Multi-regional retail performance dashboard built in Power BI with dynamic DAX calculations for Profit Margins, Average Order Value (AOV), and category revenue contributions.
