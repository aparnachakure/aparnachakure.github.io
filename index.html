04 / AI & AUTOMATION

I use AI to get unstuck.
Then I check the work.

When I’m learning or building a project, I sometimes ask AI to explain a SQL query, help me understand an error, or suggest a way to clean data. I treat its answer as a starting point, not the final answer.

See project work on GitHub ↗
01
Assist

I may ask AI to draft a query, explain an error, or suggest a way to clean data.

02
Test

I test the query where I can and compare the result with the source data and the question I’m trying to answer.

03
Improve

If a suggestion works, I keep the useful part. If it doesn’t, I revise it or check another approach.

AI can be helpful, but it can also be wrong. I try to understand the result and check it before I use it.
